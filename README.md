# 个人作品集网站

一个使用原生 HTML / CSS / JavaScript 构建的个人作品集单页网站，用于展示个人介绍、技能方向与项目作品，面向老师、同学和企业招聘人员。

## 主要功能

- **个人介绍与导航**：左侧固定边栏展示头像、个人简介、技能方向与联系方式；导航链接随页面滚动自动高亮当前所在区域
- **项目作品展示**：展示 4 个精选项目，包含项目类别标签（移动应用 / Web 应用 / 数据可视化 / AI 应用）、技术栈标签、项目简介与配图，数据由 `js/data.js` 动态渲染，便于扩展
- **深浅色主题切换**：右上角按钮一键切换深色 / 浅色主题，通过 `localStorage` 记忆用户选择，刷新后保持
- **响应式布局**：桌面端为「左侧边栏 + 主内容区」左右布局；≤960px 时自动切换为上下布局，边栏压缩为吸顶导航栏，兼容移动端

## 技术栈

- HTML5 / CSS3 / 原生 JavaScript（无任何前端框架与 UI 组件库）
- CSS 自定义属性（Design Tokens）实现主题变量化，`data-theme` 属性切换深浅色
- CSS Grid + Flexbox 响应式布局
- IntersectionObserver 实现导航滚动高亮
- localStorage 实现主题选择持久化

## 运行方式

项目为纯静态页面，无需安装依赖。

**方式一：直接打开**

双击 `portfolio/index.html` 即可在浏览器中打开。

**方式二：本地静态服务器（推荐）**

在项目根目录执行任一命令，然后访问 `http://localhost:8000/portfolio/`：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

> 提示：页面通过静态服务器访问时样式与脚本加载更稳定，且便于后续在手机上通过局域网预览。
